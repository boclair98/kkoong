# Crew v2 검증 · 2026-09-06

## 구현

- 내장 AI 이미지 생성으로 신규 20종 제작, 기존 4종 보존: 총 24종.
- 개별 투명 PNG 원본 보관. 512×512 WebP 20장 합계 1,425,806 bytes.
- 1장 54,014–98,170 bytes. 실제 알파 투명도, 가로/세로 크기, 개별 파일 존재 검사 통과.
- 8장씩 페이지, 동물 12 / 외계 6 / 로봇 6 분류, 중복 재선택을 피하는 랜덤 선택.
- 같은 방에서 사람과 봇의 캐릭터 중복 방지. 재접속은 기존 배정 유지.
- 선호 캐릭터가 사용 중이면 이번 방에만 다른 캐릭터 배정, 저장한 선호는 유지.
- 유료 구매·후원·외형별 능력 차이 없음.

## 검증 결과

- `mvnw.cmd package`: Java 테스트 13개 통과, 실패 0, 빌드 성공.
- `node --test tools/game-input.test.cjs tools/crew-catalog.test.cjs`: 19개 통과.
- 격리 Chrome 실제 서버 연결, 1440×1000 / 390×844: 갤러리 및 8인 봇 방 검사 각각 18개 통과.
- 모든 20개 새 이미지 브라우저 디코딩 성공. 24종 페이지 순회/분류/랜덤/선택→설정→서버 배정→아바타 렌더링 확인.
- 새로고침 후 선택 ID 18 유지, 해당 페이지와 히어로 이미지 일치.
- 8명이 같은 캐릭터를 요청하는 통합 테스트와 1명+봇 7명 테스트에서 8개 외형 모두 고유함.
- 모바일 실제 서버 입력 회귀 16개 통과: 사전 거절/성공, 제출 초기화, 다음 턴 초기화, 포커스 유지, 합성 한글 조합, 시간 초과.
- 360px 모바일 가로 넘침 없음. 콘솔/브라우저 오류 없음.
- 생성된 원본·화면 스크린샷 육안 확인 완료.
